# Lessons carried into this hackathon

- **Sponsor prizes are the prizes** (Landfall, 2026-11-20, won nothing). The Landfall handoff records Statsig, Senso and
  tokens& tools as never integrated. Here every cash prize is "best use of X": integrate each targeted sponsor for real
  and show it in the README and the video.
- **Not about job seeking** (Aakash, 2026-11-22, said many times). Hackathon ideas are never job-hunt tools
  (interviews, job postings, resumes) unless he asks.
- **Claims follow receipts** (Landfall). Every claim in the demo or README points at a file, a run or a URL.
- **Show the design work locally** (Landfall). Run the full design stack and give Aakash pages to open, not descriptions.
- **No recipes as a playbook** (Aakash, 2026-11-23). The organizer recipes and track-brief examples are what every team copies; BAD CREDIT was The Agent Market reskinned. Encoded as hard exclusions in docs/GROUNDING.md.
- **Read the builder, not a memory line** (2026-11-23). Designs must grow from the resume and GitHub (docs/GROUNDING.md), not "data engineer and Dagster contributor".
- **Own the churn** (2026-11-23). Aakash gave two directions (hero shooter, wrestling); the other eight concepts were mine and generic. Never describe my own churn as "we switched".
- **Verify the first-run experience, not just the mechanic** (2026-11-23 11:44). The prototype passed my fight-logic checks but opened straight into a match Aakash lost before touching a key: no title, menu, mode or character select. "Prove it works" means what a player sees from the first frame.
- **Design stack on every visual change** (2026-11-23 11:52). I built the prototype arena and HUD with no design skills and left the stack out of the art and move-lab briefs. Rule now in MultiplayerAI/CLAUDE.md; the prototype HUD/arena gets a full design-stack pass after the menu agent lands.
- **pstack shape is not pstack** (2026-11-23 16:19, owner: "if you did, how did we not reach our goal"). I printed the pstack receipt every turn but broke its core: (1) Sequence Verifiable Units: 5-8 agents on the same files at once, so every merge broke something; (2) Prove It Works: headless scripts passed while the game felt wrong; the owner found the real bugs by playing; (3) Attack the Premise: kept patching code-authored animation instead of questioning it after 13:00; (4) Subtract Before You Add: said yes to ladder, tag ladder, odds, promos, royal before one 1v1 felt solid; (5) Frame: finish line was the sponsor checklist, not "a match that feels natural"; design stack/impeccable started at 15:53. Next time: one owner per file, play it myself each merge, freeze scope once the core loop feels wrong.
- **Set up lanes before using them** (2026-11-23 17:45). Agent37 lanes have browsers at /opt/pw (PLAYWRIGHT_BROWSERS_PATH=/opt/pw); I never put that in briefs, so lanes reported "no browser" and all visual work fell back to the laptop. Before the first job: check each lane opens a browser, has the design skills copied, and has disk space.
- **Scope will always grow; queue it, never start it on top of an unstable core** (2026-11-23 17:49, owner: "that will always exist"). New ideas go to a visible queue with a one-line cost; pulled only when the current build plays clean (checked by using it); answer "queued after X" or "replaces Y, ok?", never "started". After freeze the queue becomes the judges' what-next slide.
